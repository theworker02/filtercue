# filtercue

Filter URLs and cue query parts with stable normalization.

**Site:** https://theworker02.github.io/filtercue/

## Install / run

```bash
git clone https://github.com/theworker02/filtercue.git
cd filtercue
node src/cli.js
node --test
```
